# Bluefin Insights: who can do what?

*Everything in this folder is invented: the company, the people, the clients and every message.*

## The situation

Bluefin Insights is a 25-person consumer-research and analytics firm in Gurugram. Halcyon Bank has invited it to bid for a customer-experience study across Tamil Nadu and Maharashtra, the biggest project Bluefin has ever run.

Meera Rao, the founder, needs to name the bid team by Friday 2 October. The team needs:

- SQL and data work on the bank's customer data
- banking knowledge
- survey design
- fieldwork in Tamil and in Marathi
- someone strong to present to the client

The HR skills spreadsheet is two years old, and nobody trusts it. Ananya Iyer, Head of People, has an idea: build a live skills inventory from the work people actually do.

That's your job today.

## What's in this folder

| File | What it is |
|---|---|
| `people.csv` | Everyone currently at Bluefin: name, team, role, manager, joining date and status |
| `skills_register.csv` | The HR skills spreadsheet, last updated in October 2024. Each person listed their own skills. |
| `team_chat.csv` | Three months of team chat, July to September 2026: message id, time, channel, author and message. Authors appear by their chat names, such as "Lakshmi N." |
| `project_notes/` | Six project retrospectives and handover notes, written by project leads |

There is no `CLAUDE.md` yet. In class, you'll plan the tool with Claude in the Chat tab and ask it to write one.

## The skills we track

| Group | Skills |
|---|---|
| Technical | SQL, Excel modelling, Power BI, Survey design, Statistics, Python, Machine learning |
| Client | Client presenting, Proposal writing, Handling difficult clients |
| Domain | Banking, FMCG, Retail, Healthcare |
| Languages for fieldwork | Tamil, Bengali, Marathi |
| Other | Qualitative interviewing, Mentoring, Vendor negotiation |

Levels: **1** basic, **2** working, **3** expert.
